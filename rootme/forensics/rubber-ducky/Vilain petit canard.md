We can see that it puts a downloaded image into the user's documents. And then, at the end, launches a PowerShell command but encoded. 

Let's understand the command that is being sent : 

`PowerShell -Exec ByPass -Nol -Enc`

### 1. `PowerShell`

Launches the PowerShell command interpreter

### 2. `-Exec ByPass` (or `-ExecutionPolicy Bypass`)

It's the crucial argument for the attacker. By default, Windows blocks the execution of unsigned PS scripts downloaded on the web. The Bypass option explicitly tells powershell : Do not block anything, ignore the local security policy and just execute this.

### 3. `-Nol` (or `-NoLogo`)

This option removes the copyright banner and microsoft version that displays at the top of the console when opening a PS terminal. We can suppose that it's purely used for discretion by the attacker.
### 4. `-Enc` (or `-EncodedCommand`)

This option tells PS that the following command is not raw text but rather an encoded string in Base64. It allows first to put complex commands containing parenthesis, special chars in a clean manner for windows to input. And it's also a basic form of obfuscation.
